# Texter

A simple text editor built with Python and PySide6.

## Features

- 📝 Open and save `.txt` and `.html` files
- 🎨 Formatting: **bold**, *italic*, underlined, ~~strikethrough~~
- 🌙 Dark theme
- 🔍 Zoom
- 📊 Status bar (cursor position, character count, zoom level)
- 💾 Data loss protection

## Running the App

1. Install Python 3.10 or higher
2. Install dependencies:
    pip install -r requirements.txt

3. Run:
python main.py


## Project Structure

- `main.py` — entry point
- `window.py` — Window class (UI)
- `file_ops.py` — file operations
- `styles/dark_theme.qss` — dark theme
